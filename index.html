4️⃣ GRAMMAR (20) + SENTENCE PRACTICE

Pattern 1: A は B です

Examples: わたしは がくせい です。これは ほん です。

Practice: 1. Main teacher hoon → ? 2. Ye pen hai → ?

Pattern 2: A は B じゃありません

Examples: わたしは せんせい じゃありません。

Practice: 1. Main doctor nahi hoon → ? 2. Ye kitaab nahi hai → ?

Pattern 3: A は B ですか

Examples: あなたは がくせい ですか。

Practice: 1. Kya aap student hain → ? 2. Ye kya hai → ?

Pattern 4: ～を～ます

Examples: ごはんを たべます。みずを のみます。

Practice: 1. Main kitaab padhta hoon → ? 2. Main TV dekhta hoon → ?

Pattern 5: ～に～があります/います

Examples: つくえの うえに ほんが あります。へやに ねこが います。

Practice: 1. Table par kitaab hai → ? 2. Kamre mein billi hai → ?

Pattern 6: ～へ/に 行きます

Examples: がっこうへ いきます。にほんに いきます。

Practice: 1. Main school jaata hoon → ? 2. Main Japan jaata hoon → ?

Pattern 7: ～で～ます

Examples: がっこうで べんきょうします。レストランで たべます。

Practice: 1. Main school mein padhta hoon → ? 2. Main restaurant mein khata hoon → ?

Pattern 8: ～から～まで

Examples: ９時から ５時まで はたらきます。

Pattern 9: ～てください

Pattern 10: ～てもいいですか

Pattern 11: ～てはいけません

Practice: 1. Yahan smoke nahi karna → ? 2. Yahan photo nahi lena → ?

Pattern 12: ～ないでください

Pattern 13: ～たいです
